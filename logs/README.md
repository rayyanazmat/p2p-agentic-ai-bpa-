# Representative trajectories and failure logs

This directory stores a small representative sample of workflow traces from the deterministic Phase 2 benchmark.

Files:
- `success_case_SYN-001.json`: a successful clearance trajectory with matching invoice and purchase-order evidence.
- `failure_case_SYN-041.json`: a held case with incomplete receipt evidence and policy escalation.
- `failure_summary.json`: a compact summary of the main failure categories tracked in the benchmark.

These files are included to satisfy the repository requirement for logs or a representative sample when the full logs are large.
